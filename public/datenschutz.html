Datenschutz

Germany Travel Checker ist ein statisches Informationsangebot für englischsprachige Reisende in Deutschland. Die Website bietet regelbasierte Hinweise zu Feiertagen, Sonntagsschließungen, Reisezeiträumen und mehrstädtigen Reiseplänen.

Keine Benutzerkonten

Germany Travel Checker bietet derzeit keine Benutzerkonten, kein Login und keine serverseitige Speicherung persönlicher Profile an.

Lokale Nutzung im Browser

Die eingegebenen Städte, Datumsbereiche und Reiseabschnitte werden derzeit nur zur Anzeige der Ergebnisse im Browser verarbeitet. Es erfolgt keine serverseitige Speicherung persönlicher Reiseprofile durch Germany Travel Checker.

Hosting

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können technisch notwendige Zugriffsdaten durch GitHub verarbeitet werden.

Externe Links

Germany Travel Checker kann auf externe Seiten verlinken, zum Beispiel auf Schulferienklar oder offizielle Informationsangebote. Für Inhalte und Datenschutz dieser externen Seiten sind die jeweiligen Anbieter verantwortlich.
